# Pocket Cat privacy

Public privacy documents for the **Pocket Cat** Android and iPhone apps (Android `com.pocketcat.galchi`, iPhone `com.pocketcat.app`).

- [Privacy policy](index.md) — published at [the GitHub Pages site](https://jhyang12345.github.io/pocket-cat-privacy/).
- [개인정보 처리방침 (Korean)](ko/index.md) — published at [/ko/](https://jhyang12345.github.io/pocket-cat-privacy/ko/); authoritative for players in Korea.
- [Account and data deletion](delete-account.md) — the public request route at [/delete-account/](https://jhyang12345.github.io/pocket-cat-privacy/delete-account/).
- [Support](support.md) — contact details at [/support/](https://jhyang12345.github.io/pocket-cat-privacy/support/), the App Store support URL.
- [Google Play Data Safety draft](data-safety.md) — release-review guidance for the Play Console form. New Firebase answers are a draft until submitted.

The Unity sign-in and cloud save were added to these documents on 2026-10-26. Publishing these documents and changing Play Console answers are separate release actions.

Changes to these documents are tracked in this repository's history.
